# 🎮 CHROMASHIFT

### A Single-Player Interactive Web Game

CHROMASHIFT is an interactive single-player browser-based game developed using HTML, CSS, JavaScript, and Node.js. It is designed to provide an engaging gaming experience through interactive gameplay and a user-friendly interface.

## 📌 About the Project

CHROMASHIFT is a web-based gaming project that demonstrates the use of frontend and backend technologies in game development. The project combines web design, JavaScript functionality, and a Node.js server to create an interactive gaming application.

## ✨ Project Features

- Single-player gaming experience.
- Interactive user interface.
- Dynamic game functionality using JavaScript.
- Browser-based game application.
- Score data management.

## 🛠️ Technologies Used

| Technology | Purpose |
|---|---|
| HTML5 | Webpage structure |
| CSS3 | Styling and design |
| JavaScript | Game logic and interactivity |
| Node.js | Backend server |

## ⚙️ Installation and Setup

Follow these steps to run CHROMASHIFT on your computer.

**Step 1: Clone the repository**

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

**Step 2: Navigate to the project folder**

```bash
cd chromashift
```

**Step 3: Install dependencies**

```bash
npm install
```

**Step 4: Start the server**

```bash
node server.js
```

**Step 5: Open the game**

Open your browser and visit the local URL displayed in your terminal.
